# reap-roadmap

REAP / AlphaProof 研究导航（GitHub 版，单文件离线 HTML）。

- `index.html` — 导航页：两大模块（项目 / 预备知识）、全部仓库与文档的 GitHub 链接、阅读顺序。
- `roadmap_data.py` + `gen_roadmap.py` — 生成器；`python3 gen_roadmap.py --variant=gh index.html` 可重新生成。

覆盖内容：AlphaProof（Nature 2025 + 官方伪代码 + Nexus 2026）、nanoproof、REAP、V1（REAL-Prover 7B + 价值头）、V1-1 agentic-tool、V2（实验性）、F 盘工程目录、GitHub / HuggingFace 总表；预备知识含 Lean 源码学习、MCTS+RL 笔记与 13 个主题资料。
